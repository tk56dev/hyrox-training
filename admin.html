初回セットアップ
データの書き込み・削除のために Google Apps Script を一度だけ設定してください。5分で完了します。
STEP 1 — Google Apps Scriptを開く
Google スプレッドシートを開き、「拡張機能」→「Apps Script」をクリック
STEP 2 — コードを貼り付ける
既存のコードをすべて削除し、以下をコピー＆ペーストして保存（Ctrl+S）
function doGet(e) { const action = e.parameter.action; const ss = SpreadsheetApp.getActiveSpreadsheet(); const sheet = ss.getSheetByName('Sheet1') || ss.getSheets()[0]; let result = { success: false, action: action }; if (action === 'add') { sheet.appendRow([ e.parameter.date || '', e.parameter.start || '', e.parameter.end || '', e.parameter.theme || '', e.parameter.type || '', e.parameter.notes || '' ]); result.success = true; } else if (action === 'delete') { const d = e.parameter.date; const t = e.parameter.theme; const rows = sheet.getDataRange().getValues(); for (let i = rows.length - 1; i >= 1; i--) { if (String(rows[i][0]).trim() === d && rows[i][3] === t) { sheet.deleteRow(i + 1); result.success = true; break; } } } const cb = e.parameter.callback; const body = cb ? cb + '(' + JSON.stringify(result) + ')' : JSON.stringify(result); const mime = cb ? ContentService.MimeType.JAVASCRIPT : ContentService.MimeType.JSON; return ContentService.createTextOutput(body).setMimeType(mime); }
STEP 3 — ウェブアプリとしてデプロイ
1. 右上「デプロイ」→「新しいデプロイ」
2. 種類：「ウェブアプリ」を選択
3. アクセスできるユーザー：「全員」に設定
4. 「デプロイ」→ 表示されたURLをコピー
